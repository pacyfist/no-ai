What this actually buys you

  • Stops bulk text extraction: fetch plus an HTML parse, innerText scraping, copy-paste into a chat window. The server-rendered HTML is scrambled too, so crawlers that never run JavaScript get nothing readable.
  • Does not stop a determined adversary. The generated font is downloadable and its cmap describes the substitution completely — anyone willing to parse it can invert the cipher. Rendering the page and running OCR also defeats it.
  • Costs you screen-reader output, in-page search, and copy-paste on protected text. That is the same mechanism, not a bug. Protect article bodies; leave navigation, headings, and anything assistive technology needs alone.
